# Manas Gangwani portfolio

One-page site. Plain HTML, no build step.

## Put it live on GitHub Pages

1. Create a new public repo on GitHub named exactly `manasjg.github.io`.
2. Upload these files to it: `index.html`, `Manas_Gangwani_Resume.pdf`, `photo.jpg`.
3. Go to the repo's Settings, then Pages. Set Source to "Deploy from a branch", branch `main`, folder `/ (root)`. Save.
4. Wait a minute or two. The site will be at https://manasjg.github.io

## Updating

- New resume: replace `Manas_Gangwani_Resume.pdf` with a file of the same name.
- Photo: add a square photo named `photo.jpg`. Until then the site shows "MG".
- Text: edit `index.html` directly in GitHub and commit. It updates in about a minute.
